# answer-job-questions

**No lying, no guessing.** Use these sources in this order:
1. `career/application-answers.md` (the user's standing answers, each dated)
2. `career/career-facts.md`
3. Ask the user.

Never infer work authorization, sponsorship, salary, demographics, disability, veteran status or start date.

## Steps
1. List every question on the form, required and optional, with its field type and options.
2. Fill each one from the answers bank, and mark it BANK (standing answer), FACT (from career-facts) or ASK.
3. For free-text questions ("Why us?", "Describe a time…"), draft 120 words or fewer from verified facts in the user's voice. Run the same human check as write-cover-letter.
4. For voluntary demographic questions, use the user's standing choice. Until they set one, use "Decline to self-identify."
5. For salary, never volunteer a number unless the user set one for this role. If the form requires one, use their stated target or the posted band they approved.
6. Send the user ONE message with every ASK item and the free-text drafts. When they answer something reusable, add it to `application-answers.md` with the date.
7. Watch for single-choice questions where the user gave two true answers. Pick one, and tell them which and why.
